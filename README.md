# Actividad 5
Original de Memory.py

## Descripción
Juego de memoria: hay que encontrar los pares iguales destapando dos cuadros a la vez. Al terminar se descubre una imagen.

## Cómo se usa
- Da clic en un cuadro para ver qué tiene y luego en otro para buscar su pareja.
- Si los dos son iguales, los cuadros se quedan destapados.

## Cambios realizados
- Se cuenta y se muestra el número de taps en la barra de la ventana (Edgar).
